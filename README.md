<h1>VouchAI 🚀</h1>
AI-Powered Client Testimonial & Social Proof Showcase Platform

VouchAI is a micro-SaaS application built to streamline how freelancers, agencies, and small businesses collect, analyze, and showcase client reviews. It turns raw client feedback into high-converting marketing content and embeddable website widgets automatically.

<h2>✨ Key Features</h2>
Branded Review Collection Links: Create custom, branded landing pages (/review/{space-slug}) to easily collect verified client testimonials, ratings, and photos.

AI Insights Engine: Automatically analyzes submitted reviews to extract:

Overall sentiment (Positive, Neutral, Negative)

A 1-line catchy pull-quote highlight

Pre-drafted social media posts optimized for LinkedIn and X (Twitter)

A warm, professional email reply draft to thank the client

Multi-Tenant Workspaces: Organize reviews by distinct brand spaces under a single user account.

Embeddable Widgets: Render approved testimonials directly onto external websites via customizable grid or carousel iframe widgets.

Review Moderation Admin Dashboard: Full control over approving, filtering, and curating client reviews before they go live.

<h2>🛠️ Tech Stack</h2>
Framework: Laravel 11 / 12

Authentication & UI: Laravel Breeze, Tailwind CSS, Alpine.js

Database: MySQL / PostgreSQL

Background Jobs: Laravel Queues (Asynchronous AI processing)

AI Integration: OpenAI API / Google Gemini API via Laravel HTTP Client
